# Archived: Original Dezzi (two-brand) site

This is a snapshot of the full site that was previously live at
`dezzisdesigns.studio` (redirecting to a Perplexity-hosted app at
`dezzi.pplx.app`), captured before the `dezzimode-site` repo's `index.html`
was rebuilt as a **Dezzi Mode–only** site.

It covered both halves of the brand:

- **Dezzi's Designs** — the brand/logo/web-design/social-strategy studio
  services half, with pricing tiers (Logo Only $450, Mini Brand $950, Full
  Brand System $1,800+, Social Templates $350).
- **Dezzi Mode** — the streetwear/merch label half (this content was ported
  into the live `index.html` at the repo root, restyled to the brutalist
  Void/Venom/Electric palette).

Kept here for reference in case Dezzi's Designs (the studio-services side)
gets rebuilt as its own site later — nothing here is currently linked from
the live site.

Files are the raw HTML/CSS/JS as served, unmodified.
